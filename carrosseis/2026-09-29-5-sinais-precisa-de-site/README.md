## Legenda sugerida

Instagram é vitrine. Site é endereço.

Se o seu negócio existe só dentro de uma rede social, você está construindo em terreno que não é seu. Separei 5 sinais de que já passou da hora de ter um site próprio.

Se você se identificou com dois ou mais, me manda SITE no direct.
